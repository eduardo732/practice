# Node.js + TypeScript Exercises

Technical exercises focused on **Fintech**, **Microservices**, **Event-Driven Architecture**, and **AWS Lambda** patterns.

## 📋 Exercises

| # | Topic | Key Patterns |
|---|-------|--------------|
| 1 | **Bank Transfer Validation** | Input validation, business rules |
| 2 | **Lambda Event Handler** | Event processing, aggregation |
| 3 | **Async Payment Processing** | Promise.allSettled, error handling |
| 4 | **Rate Limiter** | Time windows, throttling |
| 5 | **Event Sourcing** | State reconstruction, event replay |
| 6 | **Circuit Breaker** | Fault tolerance, resilience patterns |
| 7 | **Fraud Detection** | Pattern analysis, risk scoring |
| 8 | **Event Bus (Pub/Sub)** | Message queues, event-driven design |
| 9 | **Retry with Backoff** | Exponential backoff, error recovery |
| 10 | **Microservices Aggregator** | Service composition, parallel calls |

## 🚀 Running the Exercises

### Prerequisites
```bash
npm install -g typescript ts-node
```

### Run Individual Exercises
```bash
ts-node exercise1.ts
ts-node exercise2.ts
# ... and so on
```

## 💡 Learning Objectives

- ✅ Handle async operations with modern TypeScript
- ✅ Implement resilience patterns for distributed systems
- ✅ Build event-driven architectures
- ✅ Apply fintech security and validation patterns
- ✅ Design fault-tolerant microservices

## 📚 Topics Covered

- **TypeScript**: Interfaces, Generics, Type Safety
- **Async/Await**: Promises, Promise.allSettled, parallel execution
- **Patterns**: Circuit Breaker, Event Sourcing, Pub/Sub, Retry Logic
- **Fintech**: Payment processing, fraud detection, rate limiting
- **AWS**: Lambda handlers, event processing
